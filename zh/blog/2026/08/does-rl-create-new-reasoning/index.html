强化学习是否带来了新的推理能力？

准确率提高可能来自新能力，也可能来自已有答案的概率上升。 四篇 ICML 2026 论文提供了一组互补证据。

张恒更新于 2026 年 8 月 4 日约 12 分钟
本文目录 写在前头 先明确新能力 推理时的可达性 训练时的模式收缩 方法汇总 如何区分三种变化 参考文献

写在前头

强化学习已经成为训练推理模型的常用方法。一个模型在数学或代码任务上的 pass@1 提高后， 通常会被描述为推理能力增强。不过，pass@1 只记录第一次采样是否成功， 它没有说明正确轨迹是在训练后才出现，还是一直位于基座模型的低概率区域。

这一区别会影响对训练方法的判断。如果正确解法早已存在，训练的主要作用可能是调整概率排序。 如果正确解法原本很难在有限预算内被发现，训练可能改善了可达性。 只有当新的解题结构无法通过基座模型的推理时扩展恢复，并且能够稳定迁移到新任务时， 能力扩张的解释才更有说服力。

本文选择 Power Sampling、Verbalized Sampling、SAGE 和 G²RPO 四篇论文 [1][2][3][4]。 它们使用的任务和算法并不相同，但共同研究了一个问题。 模型能力的变化有多少来自分布内部的重新组织。

先明确什么是新能力

对 softmax 语言模型而言，几乎所有有限 token 序列都可能具有非零概率。 因此，用理论支持集判断新能力并不实用。概率为十的负二十次方的正确答案虽然存在， 在实际 rollout 预算下仍然等同于不可见。

为了讨论方便，可以引入一个与计算预算相关的可达集合。下面的记号不是某篇论文的原始定义， 而是对四篇工作的统一整理。

RB(x) = { y | 在预算 B 内可以采样并验证 y }

预算 B 可以包含采样次数、最大生成长度、验证器调用次数和推理时间。 这样一来，模型变化可以分成三个层次。

第一层改变默认答案的排名。第二层改变集合 RB(x) 的边界。 第三层还要求新的结构具有稳定性与迁移性。后面的四篇工作主要为前两层提供证据。

线索一　不改参数也能改变可见能力

Power Sampling 如何重排完整轨迹

Power Sampling 直接修改基座模型对完整回答的分布 [1]。 当指数 α 大于 1 时，高概率轨迹得到进一步放大。

pα(y | x) = p(y | x)α / Z α > 1

这里的关键是完整轨迹。简单降低 temperature 只会放大当前 token 的局部偏好。 如果模型一开始更偏向一条容易失败的捷径，局部锐化可能让错误更严重。 Power distribution 会结合后续 rollout 的质量，对早期选择进行修正。

在 Qwen2.5-7B 上，基座模型在 MATH500、HumanEval 和 GPQA 的 pass@1 分别为 0.498、0.329 和 0.278。Power Sampling 将结果提高到 0.708、0.756 和 0.349。 对应 GRPO 模型的结果为 0.740、0.561 和 0.354。 这说明一部分训练收益可以由推理时的分布锐化恢复。

Verbalized Sampling 为什么能找回尾部答案

Verbalized Sampling 研究的是另一种分布收缩 [3]。 偏好数据中的标注者往往更喜欢熟悉、流畅和典型的回答。 当多个回答质量接近时，典型性会成为额外的排序信号， 使参考分布中本来就常见的模式获得更高概率。

作者没有重新训练模型，而是让模型一次生成多个候选及其概率，再从显式分布中采样。 这种方法在诗歌、故事、笑话、对话模拟和合成数据任务上提高了输出多样性。 人工评测显示质量没有出现对应幅度的下降。

两篇工作的共同点是参数保持不变，但可观察结果发生了明显变化。 Power Sampling 调整完整推理轨迹的概率，Verbalized Sampling 调整模型表达候选分布的方式。 它们都说明默认解码结果不能直接等同于模型表示能力的边界。

线索二　训练会让正确模式彼此竞争

从 reverse KL 的稳定性到 SAGE

RLVR 中的 reverse KL 将训练策略限制在参考模型附近。 这种约束可以稳定训练，也会让低概率正确轨迹更难被采到。 SAGE 没有删除 KL 项，而是用 guide function 改写锚点 [2]。

π*(y | x) ∝ πref(y | x) exp(r / β) π*SAGE(y | x) ∝ q(x, y) πref(y | x) exp(r / β)

guide function 使用 surprisal 或 entropy 等信号定位推理分叉， 再提高低密度正确轨迹被探索的机会。SAGE 在多个数学任务上同时改善 pass@1 和高采样预算下的 pass@k。

论文所说的 support expansion 是经验支持集扩张。 一条轨迹在参考策略下仍然需要具有非零概率。 SAGE 改变的是它能否在有限 rollout 中越过可见阈值，不是凭空增加理论支持。

G²RPO 如何描述赢家通吃

G²RPO 将正确 rollout 按解法族聚类，并研究这些模式之间的概率流 [4]。 在论文的平均场近似中，标准 GRPO 会持续提高正确模式的集中度。

Ly = ||y||22

当这个量接近 1，概率质量会集中到单个正确模式。 模型仍然可能生成不同措辞，token entropy 也可能不低， 但这些回答实际使用的是同一类解题策略。

G²RPO 为稀有正确模式加入与其概率倒数相关的 advantage bonus。 在 DeepSeek-R1-Distill-Qwen-7B 上，GRPO 将平均正确模式数从 2.35 降到 1.97， G²RPO 将其提高到 6.40。AIME 2025 准确率也从 46.7% 提高到 48.9%。

这里的模式数量来自 embedding 与 DBSCAN 聚类。 绝对数值会随编码器和聚类半径变化，因此更适合比较固定设置下的相对趋势。 这也是该结果目前最重要的适用边界。

四篇工作的方法汇总

四篇论文并没有回答完全相同的问题。下面的表格将它们放到同一个分析框架中， 重点比较改变对象、主要证据和结论边界。

工作改变对象需要训练主要证据不能直接说明
Power Sampling完整轨迹分布否无奖励采样恢复部分 GRPO 收益所有 RL 收益都来自锐化
Verbalized Sampling候选分布的表达与采样否多类开放任务恢复输出多样性数学推理能力一定同步提高
SAGEreverse KL 的参考锚点是pass@1 与 pass@k 同时改善产生参考策略之外的理论支持
G²RPO正确模式之间的 advantage是模式覆盖与准确率同时提高聚类得到的模式数是内在真值

从表中可以看出，Power Sampling 与 Verbalized Sampling 研究推理阶段的能力显现。 SAGE 与 G²RPO 研究训练阶段的能力收缩。 前两篇说明不改参数也能显著改变结果，后两篇说明优化正确率时也可能损失正确解法的覆盖范围。 这两条线索共同指向概率分布，而不是简单否定强化学习的作用。

怎样区分概率重排、可达性提高与能力扩张

只比较基座模型与 RL 模型的 pass@1，无法区分三种变化。 一个更完整的实验至少需要四个步骤。

  1. 固定总预算。 对基座模型和 RL 模型使用相同的 token、rollout 与验证器预算。
  2. 绘制恢复曲线。 比较普通采样、低温采样、Power Sampling 与 RL 模型在不同预算下的 pass@k。
  3. 检查解法族。 同时报告语义聚类、程序结构和关键推理步骤，并测试聚类参数敏感性。
  4. 测试分布外迁移。 新解法如果只在训练分布内出现，更可能是概率重排。稳定的跨任务迁移提供更强的能力扩张证据。

如果基座模型通过更好的采样就能追平 RL 模型，说明已有模式的重新排序解释了主要收益。 如果 RL 使低概率模式在固定预算下稳定出现，但这些模式仍可从基座模型恢复， 更合适的表述是经验可达性提高。 如果新的解题结构无法从基座模型恢复，并且能够迁移到新的任务分布， 才有更充分的理由讨论能力扩张。

小结

四篇论文提供的证据并不支持一个简单结论。 强化学习后的准确率提高既可能包含概率锐化，也可能包含探索范围变化。 现有结果能够较好地说明已有能力如何被选择和恢复， 但对真正的新能力仍需要更严格的预算控制、模式分析和分布外实验。

因此，讨论模型是否学会新推理时，问题不应只停留在准确率提高了多少。 更具体的问题是哪些解法原本已经存在，哪些解法在固定预算下第一次变得可达， 哪些解法又能够离开训练分布继续工作。
