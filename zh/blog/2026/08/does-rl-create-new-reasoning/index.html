强化学习是否带来了新的推理能力？

pass@1 上升以后，模型究竟学会了新的推理方法，还是更容易采到原有的正确答案。 四篇 ICML 2026 论文从推理时采样与训练时模式竞争给出了不同证据。

写在前头

RLVR 论文经常从一张准确率表开始。训练后的模型在 AIME 或 MATH 上得到更高的 pass@1， 随后被描述为拥有更强的推理能力。问题在于，pass@1 只说明第一条采样结果更容易答对， 它没有告诉我们正确方法是训练后才出现，还是原本就藏在基座模型的低概率区域。

pass@k 提供了另一个观察角度。如果 pass@1 上升而较大的 k 没有同步改善， 模型可能只是更集中地重复少数高概率解法。反过来，如果不修改模型参数， 只改变采样方法就能恢复训练收益，也说明默认解码没有展示模型能够生成的全部内容。

下面依次讨论 Power Sampling、SAGE、G²RPO 和 Verbalized Sampling [1][2][3][4]。 前三篇直接研究推理模型的采样或 RLVR 训练。最后一篇研究开放式生成中的模式坍缩， 更适合作为一条旁证。四篇工作并不共享同一组假设，也不能被压缩成同一个结论。

[ICML 2026] Scalable Power Sampling

Ji 等人　训练无关的完整轨迹分布锐化　数学、代码与知识问答

论文从一个局部选择错误开始。 假设模型回答 2+2 时，第一步选择直接猜测的概率为 0.6，选择先规划再计算的概率为 0.4。 直接猜测在当前 token 上更常见，但规划分支在后面给出正确答案的概率更高。 如果把 temperature 降低到 0.25，局部优势会继续被放大，模型选择猜测的概率升到约 0.835。

Power distribution 处理的是完整回答。 给定基座模型的序列分布 p(y|x)，论文希望从下面的全局分布采样。

pα(y | x) = p(y | x)α / Z α > 1

直接计算归一化常数需要枚举未来序列。早期方法因此使用 MCMC，并带来很高的推理开销。 这篇论文把全局分布拆成低温 next-token 分布和一个 future-aware scaling factor。 对每个 Top-K 候选 token，算法生成若干未来 rollout，估计这个选择会通向怎样的完整序列， 再用 jackknife 消除 Monte Carlo 比值估计的一阶偏差。实际实现使用分块前瞻， 因此不需要在每个 token 上展开到序列结束。

实验支持的是部分恢复，而不是完全等价。 Power Sampling 在 HumanEval 上超过对应的数学 GRPO 模型，在 MATH500 上仍低于 GRPO。 它还将 MCMC 最慢设置中的单题推理时间从 2.5 分钟降到 0.22 分钟。 在 Qwen2.5-Math-7B 上，八次 rollout 的重复答案比例为 62.5%，低于 GRPO 的 83.3%。 这些结果说明基座模型中确实存在没有被普通解码充分利用的正确轨迹。 它们并不能证明所有 RL 收益都来自锐化，也没有检查训练后是否出现了新的解法结构。

[ICML 2026] SAGE

Lee、Kang 与 Hwang　重塑 reverse KL 的参考锚点　数学 RLVR

这篇论文关心的是低概率正确轨迹为什么越来越难被看见。 带 reverse KL 的 RLVR 会把训练策略限制在参考模型附近。这个锚点能够减轻奖励过拟合， 但 stationary solution 仍然按参考概率进行乘法加权。某条正确轨迹如果在参考模型中概率很低， 即使奖励为正，它也很难在有限 rollout 中进入训练批次。

π*(y | x) ∝ πref(y | x) exp(r / β) π*SAGE(y | x) ∝ q(x, y) πref(y | x) exp(r / β)

SAGE 保留 KL 约束，只把参考锚点从 πref 改成 qπref。 guide function q 在每次策略更新中保持固定，用来提高某些低密度区域的相对权重。 论文尝试了随机扰动、基于 surprisal 的 token guide，以及基于 entropy 的 branch guide。 surprisal 更容易捕捉罕见措辞。entropy 在模型面临多个可行后续方向时升高， 因而更接近作者想找的推理分叉。

empirical support 是理解这篇论文的关键。 作者把奖励正确且概率高于阈值 ε 的完成定义为经验支持集。 Theorem 4.3 给出了一条低概率正确轨迹在 SAGE 下跨过 ε 的充分条件。 这只是存在性结果。训练时并不知道哪条低概率轨迹最终正确，实际 guide 只能使用 entropy 等内在信号近似定位。

Branch guide 在三项数学数据集上取得最好的平均 pass@1 与 pass@256。 论文还在 Knights and Knaves 分布外逻辑任务上观察到更完整的 pass@k 曲线。 不过 SAGE 始终在固定参考策略的理论支持集内重新分配概率。 参考模型概率为零的轨迹仍然不可达。论文也明确指出，来自更强教师模型的蒸馏才可能引入真正新的推理模式。

[ICML 2026] G²RPO

Rad 等人　把 GRPO 写成模式空间中的概率流　AIME 数学推理

正确答案之间也会发生竞争。 G²RPO 不把每条 token 序列都视为独立策略，而是把语义上相近的正确 rollout 聚成解法族。 对一个 prompt，模型可以被粗粒度地表示为若干正确模式和错误模式上的概率分布。 在论文的 KL-free、二元验证器和平均场假设下，标准 GRPO 会使正确模式之间的差异不断放大。

Ly = ||y||22 1 / K ≤ Ly ≤ 1

当 K 个正确模式接近均匀分布时，Ly 接近 1/K。 当一个模式占据全部概率时，它接近 1。论文证明，在没有精确概率并列的情况下， GRPO 的 collision field 会让最大坐标继续占优，最后趋向 winner-take-all。 这比 token entropy 更具体，因为不同措辞可能仍属于同一类解题方法。

方法只修改每条 rollout 的 advantage。 每组 16 个 rollout 先用验证器分成正确与错误样本。正确样本经过 embedding 和 DBSCAN 聚类， 频率较低的正确簇得到与概率倒数相关的 bonus。只给正确模式加奖励会影响错误概率质量的下降速度， 因此作者又加入 neutrality correction，让消除错误答案的通道尽量保持接近标准 GRPO。

两个模型上都出现了相同方向的变化。GRPO 提高准确率，却把平均正确模式数压到基座模型以下。 G²RPO 同时提高准确率和模式覆盖。这个结论仍有明确边界。 理论使用平均场近似，主要实验集中在 AIME，聚类得到的模式不是内在真值。 只有在有限 rollout 中出现过的模式才能被重新加权，真正的长尾解法仍可能完全不可见。

[ICML 2026] Verbalized Sampling

Zhang 等人　用分布式提示恢复对齐模型的输出多样性　开放式生成与合成数据

这篇论文研究的是另一类模式坍缩。 作者在偏好数据中观察到 typicality bias。标注者在真实质量接近时， 更容易选择熟悉、流畅并且在基座模型中概率较高的回答。 在带 KL 的 RLHF 最优解中，这个偏好近似表现为对参考分布继续做 power sharpening。 常见回答因此变得更常见。

Verbalized Sampling 没有修改训练算法。它改变了问题的语义对象。 普通提示要求一个答案，最典型的输出往往是单个常见实例。 VS 要求模型给出一组候选和相应概率，最典型的输出变成一组能够代表分布的样本。 作者还比较了直接生成多个答案的 list prompt。实验显示，仅仅要求列表仍容易得到若干排行榜式的常见答案， 明确要求概率分布才是主要差别。

VS 在创意写作、对话模拟、开放式问答和合成数据中改善了多样性与质量的折中， 更大的模型通常受益更多。它还在 Tulu 的 SFT、DPO 和 RLVR 阶段都恢复了部分输出多样性。 但这些实验主要不是数学推理。它可以证明对齐后的模型仍保留未被默认提示展示的生成变化， 不能直接证明 RLVR 是否创造了新的数学推理方法。因此这里把它作为跨任务旁证，而不是与前三篇等强的证据。

方法汇总

四篇论文可以围绕概率分布建立联系，但它们改变的对象、使用的任务和能够支持的结论并不相同。

Power Sampling 说明模型参数不变时，完整轨迹采样也能显著改变准确率。 SAGE 说明 reverse KL 的稳定性伴随着低密度轨迹难以进入有限训练预算。 G²RPO 进一步指出，即使轨迹都正确，GRPO 也可能让少数解法族占据几乎全部概率。 VS 则把相似现象扩展到开放式生成。它们共同反对把默认输出直接当作模型能力边界， 但没有共同证明 RL 只是在重新排序旧答案。

回到最初的问题

读完四篇论文后，更稳妥的做法是把“新能力”分成三个逐渐变强的说法。 这个框架适合放在证据之后，而不是用来预先归类论文。

现有四篇工作的证据主要集中在前两层。要支持第三层，实验需要固定 token、rollout 与验证器预算， 比较基座模型和 RL 模型的完整 pass@k 恢复曲线，还要检查解法族是否真的具有新的程序结构或关键推理步骤。 最后还需要分布外迁移，避免把训练集中的概率锐化误认为通用能力扩张。

本文的判断
RLVR 后的准确率提升不能被简单归因于新能力，也不能被简单归因于分布锐化。 当前证据更充分地解释了已有正确轨迹如何被隐藏、发现和再次压缩。 真正的新推理结构是否出现，仍需要比 pass@1 更严格的实验设计。
